# Search Engine for Information Retrieval

A lightweight search engine project for UCI ICS web crawl data.

This project includes:
- **Indexer (`indexer.py`)**: builds a weighted inverted index from crawled HTML JSON files.
- **Retriever (`search.py`)**: supports strict AND retrieval and hybrid fallback retrieval with BM25 ranking.
- **Web App (`web_app.py`)**: local web search interface (Flask).

## Features

- Parse HTML and extract visible text with important tags boost (`title`, `h1-h3`, `b/strong`)
- Near-duplicate detection with SimHash during indexing
- 2-gram indexing (bigram terms) and retrieval-time bigram boost
- Positional index for word proximity-aware retrieval
- Anchor text indexing: anchor words are added to target pages
- Tokenization + Porter stemming
- Partial index writing for memory control
- Final merged inverted index output
- PageRank computation from crawl link graph and ranking blend at query time
- `doc_id -> URL` mapping for retrieval output
- Milestone 2 required query runner
- Milestone 3 optimized retrieval (lexicon seek + BM25 + soft fallback)
- Interactive command-line search mode

## Project Structure

- `indexer.py` — build index files
- `search.py` — query/search interface
- `DEV/` — crawled JSON dataset
- `partial_indexes/` — intermediate postings files
- `final_index/` — final index and doc map output
- `final_index/lexicon.tsv` — term byte offsets for fast postings lookup
- `final_index/doc_meta.json` — document length metadata for BM25
- `milestone2_results.json` — sample/query output file
- `milestone3_queries.md` — 24-query Milestone 3 evaluation set

## Environment

- Python 3.9+

Install dependencies:

```bash

```


## Search Usage

### 1) Run Milestone 2 required queries

```bash
python search.py --milestone2
```

Optional output file:

```bash
python search.py --milestone2 --output milestone2_results.json
```

### 2) Run a single query

```bash
python search.py --query "machine learning" --topk 5
```

### 3) Interactive mode

```bash
python search.py --interactive --topk 5
```

Hybrid mode (default):

```bash
python search.py --query "distributed systems research" --mode hybrid --topk 5
```

TF-IDF ranking:

```bash
python search.py --query "distributed systems research" --mode hybrid --ranking tfidf --topk 5
```

BM25 ranking:

```bash
python search.py --query "distributed systems research" --mode hybrid --ranking bm25 --topk 5
```

BM25 + PageRank blend (default enabled):

```bash
python search.py --query "distributed systems research" --mode hybrid --ranking bm25 --pr-weight 0.2 --topk 5
```

Disable PageRank blend:

```bash
python search.py --query "distributed systems research" --mode hybrid --ranking bm25 --no-pagerank --topk 5
```

2-gram aware retrieval example:

```bash
python search.py --query "machine learning systems" --mode hybrid --ranking bm25 --topk 5
```

Positional proximity is automatically applied for multi-term queries.

Strict AND mode:

```bash
python search.py --query "distributed systems research" --mode strict --topk 5
```

## Search Options

- `--query "..."` : run one query
- `--milestone2` : run the 4 required milestone queries
- `--interactive` : start CLI search loop
- `--mode {strict,hybrid}` : strict AND or hybrid fallback retrieval
- `--ranking {tfidf,bm25}` : ranking formula selector
- `--pr-weight X` : PageRank blend weight in `[0,1]` (default: `0.2`)
- `--no-pagerank` : disable PageRank blending
- `--topk N` : number of returned results (default: `5`)
- `--output path.json` : save results to JSON

## Notes

- If `final_index/doc_id_map.json` is missing, `search.py` can rebuild it automatically from `DEV/`.
- `search.py` expects `final_index/lexicon.tsv` and `final_index/doc_meta.json` generated by the latest `indexer.py`.
- For reproducible grading/demo output, keep `milestone2_results.json` in the repository.
